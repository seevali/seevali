### Affiant

*Sworn provenance for every AI write.*

When an AI agent proposes a write to a system of record, Affiant intercepts it, tags every field with where its value came from — stated by the user, looked up, computed, drawn from the conversation, inferred, defaulted, or simply unknown — and files the result as evidence a person can approve, reject, or amend before anything commits. Every field is judged on its own, not the write as one yes or no. Nothing writes without a decision on the record.

- [affiant](https://github.com/Sakwala/affiant) — the .NET framework. Ten packages on NuGet at `1.0.0-beta.3`, with adapters for Semantic Kernel, Microsoft Agent Framework and Microsoft.Extensions.AI.
- [affiant-protocol](https://github.com/Sakwala/affiant-protocol) — the rulebook: wire schemas, numbered invariants, and the conformance suite every implementation is held to.
- [affiant-ts](https://github.com/Sakwala/affiant-ts) — the TypeScript implementation, held to the same rulebook.
